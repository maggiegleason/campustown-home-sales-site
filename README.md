# Campus Town Home Sales Site

## What this site is for

A city-by-city view of completed home sales in the college-town dataset.

## Live site

https://github.com/maggiegleason/campustown-home-sales-site

## Data notes

Price rule: Sales under $10,000 are left out because the data description identifies them as implausible.

## Tools we used

Github CoPilot Agent

## Citation

College-town home sales dataset, version 1.0 (2026). University of Illinois-Deloitte Foundation Center for Business Emerging Technologies. Data collected March 2026.
